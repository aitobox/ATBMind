# Image Generation & Retouching Guidelines

当执行人像与艺术图片生成或修图任务时，请遵循以下专业视觉准则：

## 1. 意图解析与工具选择
- 若用户希望生成全新画面，使用 `generate_image` 工具，并根据描述提炼画面主体、光影氛围与艺术风格。
- 若用户希望在已有图片基础上修改（如修脸、显瘦、换背景、微调光影），使用 `refine_image` 工具，并提供确切的局部调整指令。
- 若用户提及特定模板关键词（如“磨皮”、“显瘦”、“服装保护”），可通过 `search_templates` 查询最匹配的修图模板 ID。

## 2. 风格与画面优化法则
- **人像摄影 (portrait_photography)**：强调 85mm 镜头景深、自然通透的真实原生肤质质感、柔和影棚光线。
- **中国风 (guofeng)**：强调东方古典雅致意境、丝绸轻盈质感、微光与水墨留白。
- **电影写真 (cinematic)**：强调变形宽银幕电影感构图、电影胶片颗粒、富有故事感的情绪布光。
- **动漫风格 (anime)**：强调干净利落的赛璐璐线条、明亮清透的色彩渐变与高动态表情。
- **赛博朋克 (cyberpunk)**：强调未来都市霓虹灯光、高对比度紫青冷暖光、雨夜与全息反射细节。
