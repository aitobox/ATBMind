# Issue #12 Spec: 构建 50 组人像精修端到端基准测试集并验证匹配准确率 (>90%)

## 1. 目标 (Objective)
建立针对 `ATBMind-Draw` 插件的 50 组端到端模糊修图口语基准测试集 (`tests/benchmarks/benchmark_draw.py`)，量化评估三层推理架构（`LatentIntentCompleter` -> `WorkflowPlanner` -> `SlotDispatcher` -> `DrawPlugin`）在大白话短句转模板组合、防畸变潜需求推导与拓扑依赖排序上的综合准确率（目标 `>= 90%`）。

## 2. 50 组基准测试集设计 (`BENCHMARK_DRAW_CASES`)
涵盖五大典型场景（共 50 组）：
1. **全身与局部塑形 + 衣物/背景防畸变联动 (15 组)**：如“把右边的人稍微变瘦，衣服别走样”、“收一下小肚子和水桶腰，后面的瓷砖墙千万别歪”、“打造直角肩和天鹅颈，条纹衬衫不能拉变形”等。
2. **面部轮廓与骨相微雕 (12 组)**：如“瘦脸收下颌线，消掉双下巴，脖子过渡自然点”、“颧骨稍微内推一点，太阳穴饱满些”、“发际线往下补一点绒毛，做出高颅顶头包脸效果”等。
3. **原生肌理肤质精修 (11 组)**：如“把脸上的青春痘和痘印修掉，但要保留真实皮肤毛孔质感”、“去一下熬夜黑眼圈和泪沟法令纹，不要假面感”、“脖子跟脸有色差，美白成自然的冷白皮”等。
4. **眼神光与立体追光光影 (6 组)**：如“眼睛放大一点更有神，加一点晶莹的眼神光”、“脸上T区加一点杂志感立体追光，去一下额头油光”等。
5. **复合多意图全链路精修 (6 组)**：如“全身微调显瘦并且锁住背景，同时做个保留肌理的清透磨皮”、“瘦腰拉长腿、收紧下颌线，衣服边缘别变形”等。

## 3. 评测指标与门禁
- **Top-K 模板命中召回率 (`template_recall`)**：期望核心模板与防畸变保护模板被选中的比例。
- **拓扑排序合法率 (`topological_valid_rate`)**：前置保护模板 (`T_CLOTH_BG_*`) 排在修形模板 (`T_BODY_SHAPE_*`) 之前或满足 `dependencies` 约束的比例。
- **综合端到端匹配准确率 (`overall_accuracy`)**：断言 `overall_accuracy >= 0.90`。
