## 1. 设计哲学与核心理念

现代桌面级 AI 原生应用（如 Raycast、Linear、Claude Desktop、ChatGPT Desktop、Midjourney）已经脱离了早期 Web 移植界面粗糙、生硬边框、过度扁平或过度复杂的极端。针对 **ATBMind** 作为“三层认知推理内核与多模态插件生态桌面平台”的定位，确立三大核心设计准则：

### 1.1 精致 (Crafted Elegance)
- **微微层次 (Layered Subtle Elevation)**：摒弃生硬的纯黑纯白或刺眼的粗边框，采用 `0.5px` 精细微弱边框结合轻柔弥散阴影，构建如同实体卡片般的精致质感。
- **质感对比 (Texture & Materiality)**：导航栏采用浅灰米白毛玻璃质感底色（`#F5F5F7`），主视口采用纯净白色画布（`#FFFFFF`），主次分明，阅读舒适。
- **细节打磨 (Attention to Nuance)**：所有的按钮、标签、输入框均经过微交互打磨（150ms 优雅过渡、状态指示绿点、聚焦光晕、平滑高度动画）。

### 1.2 实用 (Practical Utility)
- **低阻力工作流 (Low-Friction Workflows)**：
  - 会话即时搜索与过滤：面对海量历史对话，无需滚轮反复翻找，支持实时关键词匹配过滤。
  - 键盘优先体验：全局 `⌘N` 新建会话、`Enter` 发送、`Shift+Enter` 换行、`Esc` 退出弹窗、双击标题就地编辑。
  - 附件拖拽与撤销：原生图片拖入窗口立即装载为预览卡片，支持一键移除。
- **闭环迭代体验 (Closed-Loop Iteration)**：
  - 针对 ATBDraw 插件生图结果，显式提供 `[↺ 以此结果微调]` 按钮，自动将上一轮产物挂载为下一轮底图并预填引导词，实现直觉的多轮渐进式精修。

### 1.3 大方 (Generous Balance)
- **呼吸感留白 (Generous Whitespace)**：避免将所有按钮、输入框、下拉框紧凑堆叠在底部；采用浮动岛式控制台（Floating Dock Island），为多轮对话流留出宽阔视野。
- **渐进式披露 (Progressive Disclosure)**：
  - 普通纯文本模式下隐藏所有插件杂项，维持极简无干扰的输入框；
  - 挂载插件时才优雅展开参数胶囊、风格网格与模板选择器。
- **灵感驱动的空状态 (Inspiring Empty Canvas)**：新会话不再面对冰冷的空白窗口，而是呈现精致的品牌徽标、欢迎导语与 4 个精心设计的开箱即用快捷场景卡片。

## 2. 设计系统基础规范 (Design Tokens)

### 2.1 色彩系统 (Color Palette)

色彩系统遵循 Apple HIG 动态语义色彩体系，分为操作主色、背景阶梯、中性文字阶梯与状态反馈色彩。

|:---|:---|:---|:---|
| `--color-primary` | `#007AFF` | Apple 经典系统蓝 | 主按钮、选中态背景、焦点光环、进度条 |
| `--color-primary-hover` | `#0062CC` | 深邃蓝 | 主按钮悬停、激活态 |
| `--color-primary-light` | `#EBF5FF` | 柔和浅蓝 (10% 浓度) | 选中标签、高亮胶囊、插件活动背景 |

### 2.2 字阶排版 (Typography System)

在桌面平台（macOS / Windows / Linux）采用系统级现代无衬线字体栈：
```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display",
             "PingFang SC", "Segoe UI", "Helvetica Neue", sans-serif;
```

字阶规范如下：
- **Hero Title (大标题)**: `20px / 600 weight`，用于空状态欢迎语、设置标题。
- **Section Title (模块标题)**: `15px / 600 weight`，用于侧边栏顶部品牌、Header 会话名。
- **Body Regular (正文文本)**: `13px-14px / 400 weight`，行高 `1.5`，用于多轮对话气泡内容。
- **Body Medium (强调文本)**: `13px / 500 weight`，用于会话列表项标题、卡片操作按钮。
- **Caption / Footnote (脚注说明)**: `11px-12px / 400 weight`，用于时间戳、快捷键标签、参数元数据。
- **Monospace (代码与技术数据)**: `12px`, `"SF Mono", Menlo, Monaco, monospace`，用于耗时 `1.2s`、API Key 掩码等。

### 2.3 空间网格与边距 (Spacing & Grid)

以 `4px / 8px` 为基准的等比阶梯缩放：
- `4px` (`--space-xs`): 紧凑内间距、图标与文字间隙、药丸徽标内边距。
- `8px` (`--space-sm`): 按钮内边距、控件内组件间距、小列表项垂直边距。
- `12px` (`--space-md`): 卡片内部区块间距、Dock 内部控件间距。
- `16px` (`--space-lg`): 视口边缘标准内边距、消息流气泡外边距。
- `24px` (`--space-xl`): 空状态大区块留白、弹窗分区垂直间隔。
- `32px` (`--space-2xl`): 欢迎主标与引导卡片大跨度呼吸留白。

### 2.4 圆角与层级标高 (Radii & Elevation)

- **圆角体系 (Corner Radii)**:
  - 窗口外框: `12px`
  - 消息气泡 / 结果卡片 / 浮动 Dock: `14px - 16px`
  - 模态弹窗 / 浮层: `12px`
  - 按钮 / 输入框 / 下拉框: `8px`
  - 药丸标签 (Pills / Badges): `9999px` (全圆角胶囊)
- **多层微投影 (Layered Depth Shadows)**:
  - Level 1 (卡片轻浮): `0 1px 3px rgba(0,0,0,0.04), 0 0 0 0.5px rgba(0,0,0,0.06)`
  - Level 2 (浮动 Dock / 悬浮按钮): `0 4px 16px rgba(0,0,0,0.06), 0 0 0 0.5px rgba(0,0,0,0.07)`
  - Level 3 (弹窗 / Popover 浮层): `0 12px 36px rgba(0,0,0,0.12), 0 0 0 0.5px rgba(0,0,0,0.08)`

### 2.5 图标与符号规约 (Iconography)

严禁在 UI 控件中使用大杂烩式的彩色 Emoji（如 🧠、🎨、💬、⚙️、🗑️、📎、🔍、💾、↺、✕ 作为粗糙图标）。替换为统一规约：
- **微图标 (Micro Glyphs)**: 采用统一线条粗细（`1.5px`）、尺寸为 `14x14px` 或 `16x16px` 的单色 SVG 矢量符号，或者精致的字符排版符号。
- **色彩协调**: 图标色彩跟随文字语义色彩，默认继承 `--color-text-secondary`，激活态变为 `--color-primary`。

## 4. 核心功能模块详细设计

### 4.1 现代化左侧导航栏 (`SidebarWidget`)

#### A. 视觉重构要素
1. **品牌区域 (Branding Header)**:
   - 带有平滑微渐变的深色应用徽标卡片，内嵌极简线条符号与“ATBMind”字标；
   - 右侧配备现代微型胶囊徽章（`v0.1.0`），呈现科技产品的严谨感。
2. **快捷操作按钮 (`+ 新对话`)**:
   - 占据整行，采用纯白高对比度圆角背景、深色字形与高质感阴影；
   - 右侧内嵌灰色快捷键药丸标签（`⌘N`），教育用户键盘操作习惯。
3. **新增会话实时搜索栏 (Search Filter Bar)**:
   - 紧跟在新建按钮下方，配备内置搜索放大镜图标与清除按钮；
   - 输入关键字即时本地过滤会话列表（无需回车，毫秒级响应）；
   - 无匹配结果时显示温和的“未找到相关会话”提示。
4. **会话列表项 (`SessionItemWidget`)**:
   - 选中态：卡片采用全圆角矩形（`8px`），背景为温和的高对比度白底或浅蓝底，左侧有一道竖直的主色指示光条（`3px` 宽，圆角胶囊），标题变为加粗主色；
   - 未选中态：透明底色，鼠标悬停时平滑变为微弱灰底（`#EDEDF0`）；
   - 元数据展示：左侧带有插件类型小徽标（`💬 通用` 或 `🎨 生图`），中间为单行截断标题，右侧带紧凑的相对时间或日期。
5. **任务运行指示器 (`LoadingSpinner`)**:
   - 某会话在后台运行推理或生图时，列表项右侧浮现 Apple 风格径向淡出旋转刻度 Spinner，生图完毕后平滑淡出。
6. **底栏设置入口**:
   - 底部常驻 `⚙️ 偏好设置` 按钮，采用悬浮磨砂态，支持点击呼出系统级设置。

### 4.2 中央对话舞台与沉浸式空状态 (`ChatStreamView`)

#### A. 顶栏 HeaderBar
- **无缝融合**: 移除厚重的实线边框，采用 `1px solid rgba(0,0,0,0.06)` 的超细分割线；
- **可内联编辑的会话标题**:
  - 单击悬停时显示微妙虚线底框与铅笔微图标；
  - 双击就地平滑转变为 `QLineEdit`，失焦或回车即时持久化回写 SQLite；
- **插件挂载状态胶囊**:
  - 当挂载 ATBDraw 插件时，显示 `🎨 ATBDraw 图像精修` 鲜艳蓝底药丸；
  - 纯文本通用对话时，显示低饱和度的 `💬 通用对话` 灰色药丸；
- **历史管理**: 右侧设置轻量的 `清空会话` 次级动作按钮。

#### B. 沉浸式空状态画布 (`EmptyStateWidget`)
当会话没有消息历史时，主舞台不展示空白窗口，而是呈现现代 AI 应用的灵感启动看板：
1. **居中 Hero 引导**:
   - 精致的大型品牌微徽章与渐变标题：“探索灵感，与智能体协同创作”；
   - 副标题：“描述您的自然语言意图，或从下方快捷工作流快速开始”；
2. **4 组开箱即用快捷卡片网格**:
   - 卡片 1: `✨ 自然原生双频磨皮` — 保持真实肌理，抚平微瑕与暗沉
   - 卡片 2: `👗 智能全身显瘦与防畸变` — 黄金身材比例塑造，衣物背景防拉扯
   - 卡片 3: `📷 电影写真质感打光` — 增强面部立体光影与明暗层次
   - 卡片 4: `💡 自由多轮对话咨询` — 向全能 AI 智能体咨询任何问题
3. **交互闭环**:
   - 用户点击任何卡片，界面自动将对应提示词与插件状态填入底部输入控制台，并聚焦输入框。

---

### 4.3 多轮消息气泡系统 (`MessageBubble`)

#### A. 用户消息气泡 (`UserMessageItem`)
- **对齐与形态**: 居右对齐，最大宽度限制为视口的 `75%`；
- **视觉风格**: 纯净深蓝渐变色（`#007AFF` 至 `#0066CC`），字形纯白，`16px` 大圆角；
- **附件胶囊**:
  - 若包含图片输入，在气泡上方渲染高质感附件卡片；
  - 带有微缩略图、文件名、尺寸标签以及 `🔍 预览` 触发按钮。

#### B. 助手回复气泡 (`AssistantTextMessageItem`)
- **对齐与形态**: 居左对齐，最大宽度限制为视口的 `80%`；
- **视觉风格**: 纯净微浅灰卡片（`#F4F4F6`），微弱边界，`16px` 圆角；
- **顶栏标识**: 带有助手徽标与模型身份标签（如 `ATBMind Assistant`）；
- **操作快捷项**: 气泡悬停时右下角浮现 `📋 复制全文` 幽灵按钮。

#### C. 错误与重试卡片 (`ErrorResultCard`)
- 采用温和的淡粉红底色（`#FEF2F2`）搭配浅红边框（`#FECACA`）；
- 标明友好的错误原因（超时、Key 失效、网络异常）；
- 右侧配有直接重试动作按钮（`↻ 重新尝试`）。

### 4.4 ATBDraw 图像对比结果卡片 (`DrawResultCard`)

针对核心生图与精修产物，摒弃简陋的标签并排，升级为 **画廊级对比卡片**：
1. **卡片容器**: 采用纯白双层阴影容器，`14px` 圆角，微米外框；
2. **元数据信息条 (Header)**:
   - 左侧：插件标志与当前所选种子模板标签（例如 `🎨 ATBDraw · 双频原生磨皮`）；
   - 右侧：耗时指示胶囊（例如 `⏱ 1.4s`）与尺寸比例；
3. **图像双联对比视口 (Before & After)**:
   - 左右两列对称排布，内层图像容器自带 `8px` 圆角与内发光阴影；
   - 顶部悬浮毛玻璃标识药丸：“原图 (Before)” 与 “精修效果 (After)”；
   - 鼠标悬停时出现浅色高亮遮罩，提示点击放大；
4. **功能操作底栏**:
   - `💾 另存为...`: 次级按钮，快捷将精修结果导出至用户指定目录；
   - `🔍 放大查看`: 次级按钮，点击呼出全尺寸无损图片预览对话框；
   - `↺ 以此结果微调`: **核心主操作按钮 (Primary CTA)**，亮蓝色填充，点击后将当前 After 图像自动塞入底部 Dock 附件栏，预填引导词并自动滚屏，无缝进入下一轮循环！

### 4.5 悬浮式底部控制岛 (`FooterDock`)

底部控制岛是用户输入频率最高的核心中枢，采用现代 AI 桌面应用的**悬浮岛设计 (Floating Dock Island)**：
1. **形态与定位**:
   - 并非贴紧底部的死板矩形，而是带有边距（左/右 `24px`，底 `16px`）的浮动药丸卡片容器；
   - 背景为纯白（`#FFFFFF`），具备轻柔的扩散阴影（`0 4px 20px rgba(0,0,0,0.07)`）与 `1px` 微边界；
2. **顶层可插拔插件工具栏 (Plugin Toolbar)**:
   - 未挂载插件时：仅展示简洁小巧的 `+ 挂载插件 (ATBDraw)` 药丸；
   - 挂载 ATBDraw 时：
     - 插件状态胶囊：绿色圆点指示在线，带 `×` 快捷卸载；
     - 模型切换器：圆角下拉菜单（Flux.1 / SDXL / Seedream / Mock）；
     - 比例切换器：圆角下拉菜单（1:1 / 4:3 / 16:9 / 9:16）；
     - 艺术风格选择器：点击弹出 `StylePopover` 风格选择面板；
     - 模板精修选择器：可搜索/切换 360 条种子修图模板；
3. **附件暂存区域 (`AttachmentChip`)**:
   - 用户拖入或选择底图后，在输入框上方呈现精巧的附件卡片；
   - 带有 `36x36px` 圆角缩略图、文件名截断、以及平滑淡出的 `✕` 移除按钮；
4. **多行自适应输入框 (`AutoResizingTextEdit`)**:
   - 支持根据内容行数在 `40px` 到 `140px` 之间平滑无跳跃扩展高度；
   - 极简原生边框，聚焦时外层 Dock 呈现微微的蓝色焦点光环；
5. **底栏动作与提示**:
   - 键盘提示文字：“Enter 发送 · ⇧Enter 换行”；
   - 右侧圆形发送按钮（`36x36px`）：未输入内容时为浅灰禁用态，输入文字或装载附件后瞬间点亮为 Apple Blue 激活态，点击带有按压弹性反馈。

### 4.6 艺术风格网格选择浮层 (`StylePopover`)

- **弹出效果**: 对标豆包与 Midjourney 的多模态风格网格体验，基于 Frameless Popup 无边框浮动窗口；
- **容器与阴影**: `12px` 圆角，四向重阴影（`0 12px 32px rgba(0,0,0,0.15)`）；
- **网格排布**: 2 列对称布局，展示人像摄影、电影写真、中国风、动漫二次元、3D渲染、赛博朋克等风格；
- **状态高亮**: 当前选中风格呈现鲜亮蓝框与蓝底，右侧带对勾微图标。

### 4.7 偏好设置面板 (`SettingsDialog`)

- **结构**: 模仿 macOS System Settings 风格；
- **内容分区**:

- **缩放与平移**: 保持高品质双线性插值渲染，按 `Esc` 或点击右上角关闭按钮平滑退出。

## 5. 交互模式与动效规范 (Interaction & Motion)

1. **状态转换时序**:
   - 按钮悬停/按压过渡: `120ms - 180ms ease-out`
   - Popover 弹出与关闭: `150ms cubic-bezier(0.16, 1, 0.3, 1)`
   - 输入框高度自适应扩展: 与文字排版同步自适应
2. **键盘快捷键映射**:
   - `⌘N` (或 `Ctrl+N`): 无论何时聚焦，一键新建会话并自动激活输入框；
   - `⌘F` (或 `Ctrl+F`): 快捷聚焦至侧边栏会话搜索栏；
   - `Enter`: 提交输入请求并启动异步线程；
   - `Shift + Enter`: 输入框换行；
   - `Esc`: 关闭当前弹出的 Popover、ImageViewer 或 Settings 模态框。
3. **拖拽支持 (Drag and Drop)**:
   - 直接将桌面或 Finder 中的 `.png`, `.jpg`, `.webp` 拖入窗口主舞台或 Dock，自动高亮并挂载为当前轮次附件。

## 6. 暗色模式适配规范 (Dark Mode Strategy)

遵从 Apple HIG 暗色模式原则：“暗色不是纯黑，暗色是层级的延伸”：
- **Level 0 (Window Canvas)**: `#161618`（而非 `#000000`）；
- **Level 1 (Sidebar)**: `#1E1E20`；
- **Level 2 (Chat Area)**: `#1C1C1E`；
- **Level 3 (Card / Surface)**: `#252528`，外围配备 `0.5px solid rgba(255, 255, 255, 0.1)` 的微光反差边界；
- **文本层级**: Primary `#F5F5F7`，Secondary `#98989D`，Muted `#636366`；
- **主色适配**: 采用亮度更高的 `#0A84FF` 以在深色背景下保持充沛的对比度与视觉张力。
